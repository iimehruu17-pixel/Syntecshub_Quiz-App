# 🎯 Simple Quiz App

A clean and interactive Quiz Application built using **HTML, CSS, and JavaScript**. This project allows users to test their knowledge through multiple-choice questions, receive instant feedback, and view their final score.

## ✨ Features

* 📝 **12 Multiple-Choice Questions** — Test your knowledge of computer basics, HTML, CSS, and JavaScript.
* ✅ **Instant Feedback** — Correct and incorrect answers are highlighted.
* 📊 **Score Tracking** — Keep track of your correct answers throughout the quiz.
* ➡️ **Next Question** — Move to the next question after selecting an answer.
* 🏆 **Final Scoreboard** — View your score when you complete the quiz.
* 🔄 **Restart Quiz** — Restart the quiz and try again from the beginning.
* 🎨 **Interactive UI** — Simple and user-friendly interface.

## 🛠️ Technologies Used

* **HTML5** — Structure of the application.
* **CSS3** — Styling and visual design.
* **JavaScript** — Quiz logic, answer validation, score calculation, and DOM manipulation.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project

Navigate to the project folder:

```bash
cd Simple-Quiz-App
```

### 3. Run the Application

Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

No additional installations are required.

## 🎮 How to Play

1. Open the Quiz App in your browser.
2. Read each question carefully.
3. Select one of the four available answers.
4. Check the instant feedback to see whether your answer is correct.
5. Click **Next** to continue.
6. Complete all 12 questions to view your final score.
7. Click **Restart** to play again.
